# Lumi Doc 使用指南

> 本文档介绍 Lumi Doc 的功能与使用方法，帮助新用户快速上手。Lumi Doc 是一个轻量级在线文档协作平台：打开即写、自动保存，支持多人实时协同编辑、评论互动、公开分享，以及通过 AI / MCP 接入大模型工具。

## 功能速览

| 能力 | 说明 |
| --- | --- |
| 即写即存 | 标题或正文变化后自动保存，无需手动保存 |
| 多人实时协同 | 基于 Yjs 的多端实时同步，支持在线成员与光标 |
| Markdown | 导入 .md 文件、一键识别未渲染的 Markdown 格式 |
| 富文本编辑 | 标题、列表、任务列表、表格、代码块、图片、引用、分割线 |
| 划词评论 | 选区评论、线程回复、点赞、@提及、解决/重新打开 |
| 协作权限 | 申请协作 → 作者审批 → 协同编辑 |
| 实时通知 | 评论、协作申请、审批结果实时推送，未读角标 |
| 公开与分享 | 文档可设为公开进入社区，也可生成只读/可编辑分享链接 |
| AI 能力 | AI 润色、语音转写、MCP 文档工具接入 |
| 算法题库 | 发布算法题面，关联算法训练网站 |

## 一、注册与登录

Lumi Doc 使用邮箱注册，验证码 10 分钟内有效；同一邮箱是四个网站共用的唯一账号，忘记密码可通过注册邮箱重置。登录后进入个人工作台。

![注册与登录页](/uploads/02/36/023626433c2e41f834fcf22f11a25c6b5250b89b1adc054f8a4398c888ac7510.png)

## 二、工作台：我的文档

![工作台：我的文档](/uploads/e0/1a/e01ac3bb25accba28ae9464cd71878a7ea8d0345bcf1bc34d5e4037027aa74d6.png)

- **新建文档**：点击「+ 新建文档」。
- **搜索**：按标题与正文关键词实时搜索（输入停顿后自动触发）。
- **最近访问**：打开过的文档按最近访问时间优先排列。
- **拖放排序**：个人文档支持拖放调整顺序并持久化。
- **[MCP] AI 接入**：在此生成个人 MCP Token（见第六章）。
- **参与协作的文档**：他人共享给你的协作文档单独分组展示。

## 三、编辑器：即写即存

打开文档即可编辑，标题或正文变化后自动保存，顶部实时显示保存状态；未获编辑权限时自动隐藏工具栏，仅可阅读。

![编辑器：即写即存](/uploads/11/bb/11bb3f77555465a91f55ba2df4d64edbb95f473fa51e46412bf46140a9900c91.png)

### 编辑能力

- **块操作**：光标所在块的操作柄支持转换块类型（正文/标题/引用/列表/代码块/表格等）、复制、上移下移、删除，以及整块拖放排序。
- **代码块**：支持 Tab / Shift+Tab 缩进与反缩进，右上角一键复制。
- **表格**：支持列宽拖拽；块操作柄内可切换「适应窗口宽度 / 适应内容」。
- **任务列表**：支持勾选状态。
- **插图**：工具栏选择、粘贴、拖放均可插入图片，一次最多 6 张；同行多图自动等高排布。

![正文内嵌图片](/uploads/55/d2/55d253af951244e71e6ce225695d2ee7cbfe55e417ab547a46fab9a85de83b3b.png)
- **Markdown 导入**：工具栏「导入 MD」支持 .md / .markdown 文件。
- **识别 MD 格式**：一键扫描正文中未渲染的 Markdown 块级标记（标题、引用、列表、表格、代码围栏、分割线）并渲染，行内标记（加粗、斜体、删除线、链接、行内代码）一并处理。
- **大纲与文档目录**：左侧文档目录支持搜索、新建、切换文档；右侧大纲按标题层级生成，点击可定位到正文。
- **AI 润色**：点击「AI 润色」输入要求，整篇交给 Claude 润色后回填正文并自动保存。
- **语音转写**：点击工具栏麦克风或双击 Ctrl 开始/停止录音，自动转写并插入光标处。

## 四、评论与协作

### 划词评论

选中正文文字即出现评论浮层，可创建带原文锚点的评论；右侧评论面板支持线程回复、点赞、@提及成员、解决/重新打开。评论与正文双向定位，原文被编辑时锚点跟随，失效时给出提示。

![评论面板](/uploads/fa/06/fa062d7763f143d4fa3730957bbb1814b6d48d0988c097d43fc44de9d7d15e49.png)

### 协作申请与审批

- 作者可在编辑页邀请他人协作，他人也可主动申请协作。
- 申请人提出协作请求 → 作者在铃铛面板审批 → 批准后进入协同编辑，支持多端实时同步与在线成员头像。
- 被拒绝后可再次申请。

### 实时通知

顶栏铃铛合并「消息通知」与「协作请求」：未读消息、待处理协作请求以数字角标显示，支持单条已读、全部已读、清理已读，点击通知可跳转到对应评论或文档。

## 五、公开与分享

### 社区公开文档

作者可在编辑页将可见性切换为「公开」，文档即出现在「社区」页，任何登录用户可见。

![社区公开文档](/uploads/a6/eb/a6eb3082f545ff1c32614362e779b2b3ca7ac718d9674d051af90654b06e15c1.png)

### 分享链接

点击「分享」生成外链，可选择只读或可编辑两种权限：

![分享链接设置](/uploads/ec/b4/ecb4be60e7b873423c6d2573ff55d64ae8905858e49ff6ac4fb80f3acc564158.png)

- **只读**：访问者仅可阅读；
- **可编辑**：访问者挂载协同编辑，直接进入协作。

## 六、AI / MCP 接入

### 个人 Token

在「我的文档」点击「[MCP] AI 接入」生成个人 Token，明文只展示一次，可随时撤销；Token 只绑定当前用户，不保存账号密码，也不能操作他人文档或题库内容。

### MCP 工具（8 个）

- **查找**：`list_markdown_documents`、`search_markdown_documents`
- **读取**：`get_markdown_document`、`read_document_content`（分段读取，返回大纲与总行数）
- **写入**：`create_markdown_document`、`update_markdown_document`、`edit_markdown_document`（精确替换/追加/前置）
- **整理**：`move_markdown_document`（调整文档顺序）

将以下配置加入支持 stdio MCP 的 AI 客户端即可接入：

```json
{
  "mcpServers": {
    "horizon-docs": {
      "command": "node",
      "args": ["<仓库绝对路径>/mcp/src/index.js"],
      "env": {
        "HORIZON_DOCS_URL": "<站点地址>",
        "HORIZON_DOCS_TOKEN": "<个人 Token>"
      }
    }
  }
}
```

### 公开只读 Markdown 接口

无需 Token：公开或已创建分享记录的文档可通过 `GET /docs/:id/raw` 直接获取 Markdown 原文，供任何支持抓取链接的大模型读取。

### 远程 HTTP MCP

支持 ChatGPT 等仅支持远程 MCP 的客户端：填写 `https://<站点>/mcp/<secret>` 即可连接。

## 七、算法题库

在题库区域创建题目，编辑器复用相同的编辑与自动保存能力；「发布」会冻结标题与正文快照并递增版本，未发布修改不影响算法训练网站。发布后复制关联链接，算法训练网站以隔离 iframe 展示题面。

## 八、常见问题

- **如何保存？** 无需手动保存，标题或正文变化后自动保存。
- **文档默认可见性？** 新建文档默认私密，仅自己可见；可在编辑页切换为公开。
- **如何让更多人编辑？** 生成「可编辑」分享链接，或发起/接受协作申请。
- **忘记密码？** 在登录页点击「忘记密码」，通过注册邮箱重置。
- **文档链接为什么是一串随机字符？** 普通文档使用 32 位随机哈希作为公开标识，不暴露递增数据库主键；旧数字地址仍可访问并自动替换为哈希地址。

## 使用建议

- 写完后打开大纲检查标题层级
- 需要团队讨论时使用划词评论
- 对外发布前先切换「公开」并在社区确认
- 需要大模型读写文档时生成 MCP Token
