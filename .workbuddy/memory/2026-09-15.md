## 编辑页顶部吸顶修复

**问题**：编辑页（`frontend/src/views/Editor.vue`）向下滚动时，标题栏和格式工具栏会滚出视口。

**根因**：`.editor-page` 上写了 `overflow-x: hidden`。按 CSS 规则，一个轴为 `hidden` 时另一个轴的 `visible` 会被计算成 `auto`，于是 `.editor-page` 变成滚动容器；它自身高度等于内容高度并不滚动，内部 `position: sticky` 的 sticky 参照物就成了这个不滚动的容器，导致吸顶完全失效。

**改动**：
- `frontend/src/views/Editor.vue`
  - 模板新增 `.editor-sticky-head`，把 `.editor-topbar` 与 `<EditorToolbar>` 包进同一个吸顶容器（`position: sticky; top: 0; z-index: 100`）。
  - `.editor-page` 的 `overflow-x` 由 `hidden` 改为 `clip`（clip 不创建滚动容器，不破坏 sticky，仍能裁掉横向溢出）。
  - 删除 `.editor-topbar` 上原有但无效的 `position: sticky; top: 0`，以及 scoped 里写死的 `.toolbar-menu { top: 56px }`。
- `frontend/src/assets/style.css`
  - 移动端媒体查询里删除 `#app .toolbar-menu { top: 112px }`（偏移量由容器自适应，不再需要）。

**验证**：前端 `node --test` 45 项通过；`vite build` 通过（525 modules）；`node --check backend/server.js` 通过；构建产物确认 `.editor-page{overflow-x:clip}`、`.editor-sticky-head{position:sticky;top:0;z-index:100}`，`.editor-topbar` 已无 sticky。本机没有安装任何浏览器，无法做浏览器端视觉验收。

## 块操作柄失焦后无法转换/拖动（fix: a493e5e）

**现象**：光标放进代码块后左侧 `⋮⋮` 操作柄出现，但点击完全没反应（转换菜单不出现），也拖不动。

**根因**：TipTap 的 `editor.isFocused` 在编辑器 DOM blur 时被置为 false。点击操作柄（Teleport 到 body 的按钮）会先让编辑器 blur → tiptap 派发一个带 blur meta 的 transaction → `EditorBlockMenu` 的 `transaction` 监听（`updatePosition`）在 rAF 里看到 `!isFocused` 就 `hideMenu()`，`visible=false` 让操作柄 `display:none`：mouseup 时元素已隐藏，**click 事件根本不产生**；原生 drag 也因为元素消失而中断。`hideMenu` 是 `a2453f9`（对齐块操作柄并高亮目标行）引入的，所以代码块拖放从未真正做过浏览器验收。所有块类型都有这个 bug，不只是代码块。

**改动**：
- `frontend/src/utils/blockMenu.js`：新增 `shouldShowBlockMenu({isDestroyed,isEditable,isFocused,interacting,hasTarget})`——操作柄属于「正在操作的块」，焦点只是其中一个显示条件。
- `frontend/src/components/EditorBlockMenu.vue`：
  - `updatePosition` 不再因失焦收起，改为 `shouldShowBlockMenu` 判定；`interacting = dragging || open || pointerOnMenu`。
  - 根节点加 `pointerenter/leave`，触发按钮加 `@mousedown="markMenuPointer"`（mousedown 早于 blur，确保失焦瞬间被判定为"在操作柄上"）。
  - `setOpen(true)` 同时把 `visible` 置 true（原来只改 `open`，根元素仍隐藏）。
  - 高亮事务用 `suppressPositionSync` 屏蔽自身回灌的 `updatePosition`。
  - 点正文外空白收起操作柄、点回正文只收起菜单、新增 `Esc` 收起；`hideMenu` 里复位 `pointerOnMenu` 防止残留。
- 新增 5 项单元测试（前端共 45 项通过）。

**验证**：45 项前端测试 + `vite build`（525 modules）+ `node --check backend/server.js` 通过；临时无头 Chrome（CDP）验收页跑 11 项并全通过：代码块入块显示操作柄、点击打开菜单、目标块高亮、Esc 收起、代码块转正文、点击空白收起、代码块上下拖放换位、正文打开菜单、菜单项下移、正文整块拖动。修复前同一脚本可复现失败。验收页与驱动脚本未入库（已列入下一步）。
